# 셸 자동화 작성 기준

- 실행 스크립트는 Bash strict mode(`set -euo pipefail`)를 사용한다. source되는 셸 설정은 호출자의 옵션에 미치는 영향을 확인한다.
- 셋업과 설정 추가는 반복 실행 시 중복·손실이 없게 작성한다. Stow로 연결된 설정은 링크의 실제 원본을 수정하고 대상 부모 디렉토리를 준비한다.
- 기존 설정 덮어쓰기 전 충돌하지 않는 백업을 만들고, 설정 추가는 기존 선언 여부를 확인한다.
- 임시 경로는 mktemp로 할당하고 종료 시 정리한다. 삭제 대상은 비어 있지 않고 의도한 경로인지 확인한다. 유효성 검사 없는 광역 삭제를 구현하지 않는다.
- 관리자 권한보다 사용자 범위 설치를 우선한다. 이 dotfiles 저장소의 도구 선언은 `contexts/dotfiles/references/040-toolchain-management-standard.md`를 따른다.
- 현재 셸·OS에서 명령 지원을 확인하고 변수의 단어 분할·경로 공백을 처리한다. 셸 수정에는 shellcheck와 관련 회귀 검사를 실행하고, 파일 조작은 격리 환경에서 2회 연속 실행해 멱등성을 확인한다.
