# dotfiles 시크릿 보호

- **[MUST] 시크릿 원본 분리:** 자격 증명은 저장소 밖 `~/.zshrc.local`, `~/.gitconfig.local` 등에 두고, 추적 파일에는 환경 변수·로컬 파일 참조만 구현한다.
- 프라이빗 키 조회 승인과 출력 마스킹은 `base.AGENTS.md`를 따른다. 키의 실제 내용을 예제·검증 로그로 출력하지 않는다.
- 새 자격 증명 로직 또는 원격 푸시 전에는 설치된 trufflehog나 trivy로 시크릿을 검사한다. 커밋 훅의 보안·린트 실패는 원인을 해결하고 훅을 우회하지 않는다.
- 시크릿 스캔 완료를 주장하려면 trufflehog의 verified/unverified 합계 0건과 자격 증명 파일의 Git 추적 제외를 확인한다. 도구가 없으면 미검증 범위를 보고한다.
- 유출이 발견되면 노출을 확대하는 실행을 중단하고 폐기·교체를 안내한다. 히스토리 정리는 git-filter-repo나 BFG 사용을 제안할 수 있으나 원격 강제 푸시는 명시적 승인을 받는다.
