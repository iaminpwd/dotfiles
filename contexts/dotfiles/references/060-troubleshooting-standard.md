# 로컬 환경 오류 진단

- PATH 오류는 현재 PATH, `command -v <tool>`, 관련 설정의 덮어쓰기 위치를 확인한다. 원인 확인 없이 `.zshrc`에 경로를 반복 추가하지 않는다.
- 셸 로드 오류는 필요한 경우 `bash -x` 또는 `zsh -x -i -c exit`로 추적한다. 추적 출력이 로컬 시크릿을 노출할 수 있으므로 민감한 설정은 출력에서 제외한다.
- 에이전트의 셸은 독립 세션일 수 있다. 설정 로드와 검증 명령을 같은 셸 실행에 두고 결과를 확인한다.
- Stow 충돌은 기존 파일을 조사하고 충돌하지 않는 백업 경로로 보존한 뒤 링크를 재시도한다. 연결 후 `[ -L <link> ] && [ -e <link> ]`로 끊어진 링크 여부를 확인한다.
- 수정한 셸 코드에는 shellcheck와 관련 회귀 테스트를 실행한다. 셋업·파일 조작은 격리 환경에서 반복 실행해 중복·손실 여부를 확인한다.
