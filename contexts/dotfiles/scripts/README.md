# Dotfiles Scripts Directory

이 디렉토리는 AI 에이전트의 워크플로우를 자동화하고, 프롬프트 코퍼스를 검증하며, 에이전트의 자가 진화(Self-improving)를 돕는 스크립트들을 포함하고 있습니다.

## 🤖 AI 메타 인지 & 로깅 파이프라인 (AI Self-Reflection Pipeline)

에이전트가 무슨 작업을 했는지 기록하고, 연속 실패 시 스스로 프롬프트를 고칠 수 있도록 돕는 시스템입니다.

- **`agent-edits-hook.sh`**: (PostToolUse 훅) 에이전트가 도구를 사용해 파일을 편집할 때마다 기계적으로 어떤 파일을 건드렸는지 `.agent-state/edits.log`에 자동 기록합니다.
- **`log-edit.sh`**: (에이전트 수동 호출) 에이전트가 코드를 수정한 뒤, "어떤 룰북(프롬프트)의 지시를 따라 이 코드를 수정했는지" 작업 의도와 근거를 명시적으로 로그에 남깁니다.
- **`prompt-flywheel.sh`**: (에이전트 실패 시 가동) 에이전트가 3번 연속으로 작업에 실패했을 때 가동됩니다. `edits.log`를 분석하여 "아, 내가 이 프롬프트를 따르다가 실패했구나"라고 스스로 원인을 파악하고 룰북 개정안을 역제안합니다.

## 📝 프롬프트 및 코드 린터 (Linters)

코드와 룰북(프롬프트)의 정합성을 강제하고 오류를 사전에 차단합니다.

- **`prompt-lint.sh`**: 마크다운 룰북(Prompt Corpus) 전용 린터입니다. 여러 에이전트 도메인 간의 개념 중복, 크로스 벤더 용어 오염, 마크다운 코드 펜스 깨짐 등을 엄격하게 정량 검사합니다.
- **`idempotency-check.sh`**: 쉘 스크립트에 멱등성(Idempotency)이 보장되어 있는지 검사합니다. 예를 들어 상태 확인 없이 `>>` (Append)를 남발하는 코드를 잡아냅니다.
- **`semantic-commit-lint.sh`**: 원자적 커밋(Atomic Commit) 분석기입니다. 한 번의 커밋에 너무 많은 도메인이나 파일이 섞여 들어가는 것을 방지하고 시맨틱 커밋 컨벤션을 강제합니다.

## 🛠️ 유틸리티 (Utilities)

- **`broken-symlink-detector.sh`**: 홈 디렉토리(`~/`) 하위의 깨진 심볼릭 링크(고아 링크)를 탐지하여 시스템 환경을 깔끔하게 유지하도록 돕습니다.
